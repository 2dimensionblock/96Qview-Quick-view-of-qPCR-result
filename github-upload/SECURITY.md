# 安全问题反馈

此项目在本机解析用户选择的表格。网页端不提供 Node.js 能力；桌面渲染器启用隔离和沙箱。主动点击参考文献链接会交给外部浏览器。

如果发现任意代码执行、文件越权读写等问题，请优先使用 GitHub 仓库 Security 页的 **Report a vulnerability**（需要维护者先启用 private vulnerability reporting）。若入口尚不可用，请仅提交不含利用细节的 Issue，请维护者建立私密报告渠道。

不要在公开 Issue 中上传访问令牌、签名密钥、私人数据或可直接利用的敏感细节。当前未承诺固定的安全更新期限；发布前应检查桌面运行环境的支持状态。升级 Electron 后需重新测试打包与导出。
