# 参与贡献

请先阅读 README 中的源码范围说明。桌面入口为 `app/main.cjs`；新功能源码在 `frontend/`。修改后生成 `app/index.html` 并一并提交，避免直接改动会被下一次构建覆盖的产物。

提交问题时说明操作系统、程序版本、输入格式、复现步骤和预期结果。优先使用仓库的模拟数据；需要最小复现表格时，请自行生成或移除真实样本名称、人员信息和未公开实验数据。

提交修改前运行：

```bash
npm ci
npm run build:frontend
npm run check
npm test
```

涉及桌面行为或导出时，还应在 Windows 上运行构建和冒烟测试。涉及计算方法时，用可手算的小数据说明预期 ΔCt、ΔΔCt 和误差线，不仅检查图是否出现。

PR 应简要说明修改原因、影响范围、验证结果和剩余限制。不要提交 `node_modules`、EXE、签名证书、令牌或实验原始数据。修改依赖时同步锁文件和第三方声明。
