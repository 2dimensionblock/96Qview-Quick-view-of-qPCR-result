# 数据格式与模拟示例

96Qview 1.1 新增样本命名和 96 孔自定义规则，见 [1.1 使用说明](96QVIEW_1.1.md)。明确映射的基因、组别和时间列始终优先于样本名称推断。

推荐使用一行表头、每行一个孔的长表。不要把不同基因的 Cq 放在不同数值列中。XLSX 文件可以在界面选择工作表；表头之前有仪器信息时，请核对自动识别结果。

| 推荐列名 | 含义 | 示例 |
| --- | --- | --- |
| `Well` | 孔位 | A1 |
| `Sample` | 样本名称 | Control_0_R1 |
| `Gene` | 检测基因/项目 | Reference 或 GeneX |
| `Group` | 实验组别 | Control 或 Treatment |
| `Time` | 时间点或横轴标签 | 0、12、24、48 |
| `BioRep` | 生物重复编号 | R1、R2、R3 |
| `Cq` | Ct/Cq 数值 | 21.305 |

程序支持常见中文表头，如“孔”“样本名称”“检测项目”“组别”“时间点”“生物重复”。导入后仍应检查列映射。最重要的是正确识别基因和 Ct/Cq，并确认分组、时间及重复编号符合实验设计。

## 重复与内参

同组、同时间、同 `BioRep` 内，一个基因可有多个技术孔。生物重复模式先合并这些技术孔；不同生物样本必须使用不同编号。

默认按组别、时间和生物重复匹配内参。配置“共用某组内参”后，内参组别被替换为所选组，其他匹配维度仍需一致。没有匹配内参的目标数据无法得到有效 ΔCt。

不要把单个样本的多个技术孔标为不同的生物重复。仅有技术孔时，请使用技术孔模式并按技术波动解释误差线。

## 模拟文件

`examples/synthetic_96_wells.csv` 完全由规则生成，不含真实实验数据：

- 2 个基因：Reference、GeneX。
- 2 个组：Control、Treatment。
- 4 个时间点：0、12、24、48。
- 每个组、时间点有 3 个生物重复，每个基因有 2 个技术孔。
- 共 96 行，孔位 A1–H12，每个孔位只出现一次。

推荐设置：内参 **Reference**；校准组 **Control**；校准时间 **0**；重复类型选**生物重复**。

对照目标的基础 ΔCt 为 5；处理组各时间点基础 ΔCt 为 5、4.4、3.6、3。生物重复偏移为 −0.12、0、0.12，技术孔偏移成对抵消。`synthetic_96_expected_summary.csv` 给出生物重复模式下的预期 2^−ΔCt 均值、SD、SEM，用于核对程序。

重新生成两个示例文件：`node scripts/generate-example.mjs`。

## 缺失值

“检测类型 / Type / Task”标为阴性、Negative、NTC、无模板或空白对照的孔默认排除。若被选作内参的孔具有阴性标签，1.1.1 会提示冲突；只有确认该孔实际为内参样本时，才点击“将这 … 孔用作内参”。此操作可撤销并记录在导出质控信息中。明确标为 NTC、无模板或空白对照的孔继续排除。详见 [使用说明](96QVIEW_1.1.md)。

空白、NoCq、Undetermined 和非正 Ct 按缺失处理，不以 0 或 40 替代。默认保留有限正 Ct；高 Ct 提示与用户设置的排除阈值不是同一回事。原始数据表请另外保存，本程序不代替实验记录系统。
