# 计算方法

## ΔCt 与绘图

目标孔的 ΔCt 为目标 Ct 减去匹配内参 Ct 均值。内参匹配使用组别、时间点和生物重复编号；共用内参设置只替换内参组别。

技术孔模式对每个目标孔计算 ΔCt 和 `2^(−ΔCt)`，再汇总这些转换后的数值。参考 Ct 均值在误差计算中视作固定值，因此误差条不包含内参估计的不确定性。

生物重复模式在每个生物重复内分别平均目标和内参技术孔的 Ct，再计算 ΔCt 和 `2^(−ΔCt)`，最后在生物重复之间汇总。

**点的位置是 `mean(2^(−ΔCt))`，通常不等于 `2^(−mean(ΔCt))`。**

## ΔΔCt 与校准

`ΔΔCt = ΔCt − mean(ΔCt(calibrator))`。程序先在每个校准生物单位内平均 ΔCt，再对单位等权平均；未提供生物编号时，校准技术孔作为一个单位。请根据实验设计选择校准组和时间。

改变校准设置影响 ΔΔCt，不改变 2^−ΔCt 折线图。本程序当前绘图不使用 2^−ΔΔCt。

## 误差线

```text
SD  = sqrt(sum((x − mean(x))^2) / (n − 1))
SEM = SD / sqrt(n)
```

`x` 为转换后的 2^−ΔCt。技术孔模式中的 `n` 是有效目标技术孔数；生物重复模式中的 `n` 是有效生物重复数。`n < 2` 时 SD/SEM 留空，不画误差线。缺失时间点断线，不自动填补。

## 解释边界

2^−ΔCt 是基于内参归一化的相对表达指标，不是绝对拷贝数。基于 2 的计算假定目标和内参扩增效率接近且近似 100%，并依赖内参稳定性。程序不验证引物效率、熔解曲线、扩增特异性和实验设计；不会自动给出显著性结论。

有关 Ct 相对定量的实验背景，可参考 [Applied Biosystems 相对定量指南](https://assets.thermofisher.com/TFS-Assets/LSG/manuals/cms_042380.pdf)。该链接需联网；上述内容描述本程序实际采用的计算规则。
